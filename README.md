# Turill Financial V2

Node.js + Express + Tailwind CSS website with a concentrated-stock conversion funnel.

## Run locally

```bash
npm install
npm run build:css
npm start
```

Open:
- http://localhost:3000
- http://localhost:3000/concentrated-stock.html
- http://localhost:3000/stock-analyzer.html
- http://localhost:3000/stock-review.html
