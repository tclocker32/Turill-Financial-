How to paste it in

  1. Gmail: Settings (gear) → See all settings → General → scroll to Signature → Create new → paste into the box → Save Changes at the bottom.
  2. Outlook (desktop): File → Options → Mail → Signatures → New → paste → OK.
  3. Outlook on the web: Settings (gear) → Mail → Compose and reply → paste into the signature box → Save.
  4. Apple Mail: Mail → Settings → Signatures → + → paste, and untick Always match my default message font.

If the logos show as empty boxes after pasting, your mail program is blocking remote images in the preview — they will still appear for the person receiving your email.
